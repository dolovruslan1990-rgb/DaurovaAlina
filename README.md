# Random Password Generator

**Автор:** [Ваше Имя Фамилия]

## Описание

Random Password Generator — это десктопное приложение с графическим интерфейсом для генерации надёжных случайных паролей с настраиваемыми параметрами. Программа позволяет:

* выбирать длину пароля (от 4 до 32 символов);
* указывать типы символов для генерации (цифры, буквы, спецсимволы);
* мгновенно генерировать пароли по заданным критериям;
* просматривать и хранить историю сгенерированных паролей;
* сохранять историю паролей между запусками приложения (в формате JSON).

Приложение разработано на языке Python с использованием стандартной библиотеки GUI — Tkinter.

## Установка и запуск

### Требования

* Python 3.6 или выше;
* стандартные библиотеки Python: `tkinter`, `random`, `json`, `os`, `datetime` (устанавливать вручную не требуется).
